Overview

      
A Slope64 input file describes a trapezoidal embankment sitting on a flat foundation layer. Each parameter is preceded by a quoted label — the label is ignored by the solver, only the value on the next line matters.


      
Geometry

      
The mesh is defined by five dimensions:

      

        
ParameterDescription

        
          
w1Width of flat crest (top of embankment)

          
s1Horizontal run of the slope face

          
w2Foundation width beyond the toe

          
h1Height of embankment

          
h2Thickness of foundation layer

        
      

      
The slope angle follows from arctan(h1 / s1). All dimensions share the same unit (typically metres).


      
Mesh density

      

        
ParameterDescription

        
          
nx1Elements across embankment + slope

          
nx2Elements in foundation beyond toe

          
ny1Elements through embankment height

          
ny2Elements through foundation depth

        
      

      
Coarser meshes run faster; finer meshes give more accurate FoS. Values of 10–30 per zone are typical.


      
Material properties

      
Set np_types to the number of material zones. For each zone, provide six values on one line:

      
phi   c   psi   gamma   E   nu

      

        
SymbolMeaningTypical units

        
          
phiFriction angledegrees

          
cCohesionkPa

          
psiDilation angle (0 = non-dilating)degrees

          
gammaUnit weightkN/m³

          
EYoung's moduluskPa (e.g. 1e5)

          
nuPoisson's ratio— (e.g. 0.3)

        
      

      
If np_types > 1, follow with an element-type array assigning each element to a zone (row-by-row, bottom to top).


      
Other parameters

      

        
ParameterTypical valueNotes

        
          
k_h0.0Pseudo-static horizontal acceleration; 0 for static analysis

          
nosurf0Number of phreatic surface points; 0 = dry

          
gam_w0.0Unit weight of water (9.81 kN/m³ if seepage is active)

          
limit1000Maximum iterations per SRF step

          
fos_tol0.02Convergence tolerance on FoS (±0.02 is standard)
