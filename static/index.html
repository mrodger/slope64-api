User Manual

      
    

    


      
What is Slope64?

      
Slope64 is a finite element slope stability program by D.V. Griffiths (Colorado School of Mines). It uses the strength-reduction method (SRM): soil strength is progressively reduced until the mesh cannot converge, giving the Factor of Safety directly -- without assuming a failure surface shape.

      
Reference: Griffiths & Lane (1999), Geotechnique 49(3), 387-403.

Reading the results


      
Factor of Safety

      

        
ColourLabelCriterion

        
          
GreenStableFoS >= 1.5

          
AmberMarginal1.2 <= FoS < 1.5

          
RedUnstableFoS < 1.2

        
      

      
These thresholds reflect common geotechnical practice. The appropriate minimum FoS for a given project depends on consequence of failure, parameter uncertainty, and applicable standards.


      
Convergence plot

      
Shows maximum nodal displacement vs. Strength Reduction Factor (SRF) for each trial step. Filled points converged within the iteration limit; cross markers did not -- they indicate the mesh has reached or passed the failure condition. The true FoS lies between the last converged step and the first failed step.


      
Strength Reduction Steps table

      

        
ColumnMeaning

        
          
Trial SRFStrength reduction factor applied in this step

          
Max displacementMaximum nodal displacement across the mesh

          
IterationsNewton-Raphson iterations taken

          
StatusConverged within limit / failed (hit ceiling)

        
      

      
The program uses bisection search: it brackets the FoS by doubling SRF until failure, then halves the interval to within fos_tol.

Input file reference


      
Geometry

      
         |<- w1 ->|
         +--------+
        /          \  ^ h1
       /   slope    \
      /  <- s1 ->    \
------+               +------+
      <-    w2    ->         | h2
------------------------------+

      

        
ParameterDescription

        
          
w1Width of flat crest (top of embankment)

          
s1Horizontal run of the slope face

          
w2Foundation width beyond the toe (0 = no foundation)

          
h1Height of embankment

          
h2Thickness of foundation layer (0 = no foundation)

        
      

      
Slope angle = arctan(h1 / s1). All dimensions in the same unit (typically metres).


      
Mesh density

      

        
ParameterDescription

        
          
nx1Elements across the embankment (including slope face)

          
nx2Elements in foundation beyond the toe

          
ny1Elements through embankment height

          
ny2Elements through foundation depth

        
      

      
10-30 elements per zone is typical. Finer meshes are more accurate but slower.


      
Material properties -- one line per zone: phi  c  psi  gamma  E  nu

      

        
SymbolMeaningUnits

        
          
phiFriction angledegrees

          
cCohesion (use undrained shear strength for phi=0 analysis)kPa

          
psiDilation angle (0 = non-dilating, recommended)degrees

          
gammaUnit weightkN/m3

          
EYoung's moduluskPa (e.g. 1e5)

          
nuPoisson's ratio-- (e.g. 0.3)

        
      

      
Set np_types to the number of material zones. If np_types > 1, follow the property block with an element-type array assigning each element to a zone (rows bottom-to-top, left-to-right). See ex2 or ex3 for examples.


      
Seepage and water

      

        
ParameterNotes

        
          
nosurfNumber of phreatic surface points (0 = dry analysis)

          
surfx, y coordinate pairs defining the phreatic surface

          
gam_wUnit weight of water (0 = dry; 9.81 kN/m3 metric when seepage active)

        
      


      
Other parameters

      

        
ParameterTypical valueNotes

        
          
k_h0.0Pseudo-static horizontal acceleration factor (e.g. 0.25 for 0.25g seismic)

          
limit1000Maximum iterations per SRF step; increase to 2000 for difficult problems

          
fos_tol0.02FoS bisection tolerance (result accurate to +/-fos_tol)

Limitations

      
    
        
  • Geometry -- Trapezoidal embankment on flat foundation only. Irregular topography, benched slopes, and retaining structures are not supported.
    • 
        
  • Failure mechanism -- SRM finds the critical mechanism automatically; it is not constrained to circular surfaces, so FoS is generally lower (more conservative) than limit-equilibrium methods.
    • 
        
  • Constitutive model -- Elastic-perfectly plastic Mohr-Coulomb only. No strain-softening, creep, or partial saturation.
    • 
        
  • Pore pressures -- Phreatic surface only. Flow nets and pore pressure coefficients (ru) are not available.
    • 
        
  • Convergence -- If FoS shows N/A, check that material properties are physically reasonable and mesh density is adequate. Increasing limit may help.
    • 
      


    

  







  

    

    

      
.dat File Format Reference

      
    

    


      
Overview

      
A Slope64 input file describes a trapezoidal embankment sitting on a flat foundation layer. Each parameter is preceded by a quoted label -- the label is ignored by the solver, only the value on the next line matters.


      
Geometry

      
The mesh is defined by five dimensions:

      

        
ParameterDescription

        
          
w1Width of flat crest (top of embankment)

          
s1Horizontal run of the slope face

          
w2Foundation width beyond the toe

          
h1Height of embankment

          
h2Thickness of foundation layer

        
      

      
The slope angle follows from arctan(h1 / s1). All dimensions share the same unit (typically metres).


      
Mesh density

      

        
ParameterDescription

        
          
nx1Elements across embankment + slope

          
nx2Elements in foundation beyond toe

          
ny1Elements through embankment height

          
ny2Elements through foundation depth

        
      

      
Coarser meshes run faster; finer meshes give more accurate FoS. Values of 10-30 per zone are typical.


      
Material properties

      
Set np_types to the number of material zones. For each zone, provide six values on one line:

      
phi   c   psi   gamma   E   nu

      

        
SymbolMeaningTypical units

        
          
phiFriction angledegrees

          
cCohesionkPa

          
psiDilation angle (0 = non-dilating)degrees

          
gammaUnit weightkN/m3

          
EYoung's moduluskPa (e.g. 1e5)

          
nuPoisson's ratio-- (e.g. 0.3)

        
      

      
If np_types > 1, follow with an element-type array assigning each element to a zone (row-by-row, bottom to top).


      
Other parameters

      

        
ParameterTypical valueNotes

        
          
k_h0.0Pseudo-static horizontal acceleration; 0 for static analysis

          
nosurf0Number of phreatic surface points; 0 = dry

          
gam_w0.0Unit weight of water (9.81 kN/m3 if seepage is active)

          
limit1000Maximum iterations per SRF step

          
fos_tol0.02Convergence tolerance on FoS (+/-0.02 is standard)
